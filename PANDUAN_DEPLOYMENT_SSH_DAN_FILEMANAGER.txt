1. PENJELASAN: BAGAIMANA CARA SAYA (AI) MELAKUKAN DEPLOYMENT KE HOSTING ANDA
========================================================================================
Mungkin Anda bertanya-tanya: "Kenapa AI bisa langsung deploy tanpa membuka browser cPanel?"

Jawabannya adalah melalui jalur Remote Terminal & SFTP:
1. Protokol SSH (Secure Shell) & SFTP (Secure File Transfer Protocol):
   Di komputer lokal Anda sudah terpasang pustaka (library) bernama "ssh2" di Node.js.
   Script kami membuka koneksi terenkripsi langsung ke server VPS Anda melalui Port 2223.

2. Pengiriman File (File Transfer):
   Setelah koneksi SSH terhubung dan terotentikasi, script menggunakan modul SFTP untuk 
   mengunggah file-file yang baru saja diubah (misalnya app.js, index.html, cmsController.js) 
   langsung menimpa file lama di folder target di server hosting.

3. Eksekusi Perintah Remote (Remote Command Execution):
   Setelah file berhasil diunggah, script mengirim perintah remote bash ke server hosting:
   "pm2 reload mci-approve-backend"
   Ini memerintahkan PM2 (Process Manager) di server untuk me-reload proses backend Node.js 
   sehingga source code baru langsung aktif tanpa membuat server mati (zero-downtime).

4. Verifikasi Kesehatan (Health Check):
   Sistem langsung melakukan pengetesan otomatis ke:
   https://approveanywhere.bprshikmciyk.co.id/api/health
   Jika server merespons "HTTP 200 OK", maka proses deployment dinyatakan sukses 100%.

6. PERINTAH-PERINTAH PENTING PENGELOLAAN BACKEND (PM2)
========================================================================================
Jika Anda membuka Terminal via SSH (Putty / CMD) atau via Terminal cPanel:

1. Melihat Status Backend (Apakah aktif atau mati):
   pm2 status

2. Memuat Ulang Backend (Tanpa Downtime):
   pm2 reload mci-approve-backend

3. Memulai Ulang Backend (Restart Penuh):
   pm2 restart mci-approve-backend

4. Melihat Catatan Log Error (Jika ada kendala):
   pm2 logs mci-approve-backend --err --lines 50

5. Melihat Catatan Log Akses & Aktivitas Terbaru:
   pm2 logs mci-approve-backend --lines 50

6. Melihat Penggunaan Memori & CPU Server Secara Real-Time:
   pm2 monit

7. TROUBLESHOOTING & CHECKLIST VERIFIKASI PASCA-DEPLOY
========================================================================================
1. TAMPILAN BELUM BERUBAH DI BROWSER SETELAH DEPLOY?
   Penyebab: Browser menyimpan cache file JavaScript dan Service Worker PWA.
   Solusi:
   - Di PC: Tekan kombinasi tombol [Ctrl + Shift + R] atau [Ctrl + F5] (Hard Refresh).
   - Di Smartphone: Hapus cache browser di Pengaturan, atau buka via Mode Penyamaran 
     (Incognito Tab).

2. SERVER MENGALAMI 503 SERVICE UNAVAILABLE?
   Penyebab: Backend PM2 belum berjalan atau sempat terhenti oleh sistem cPanel.
   Solusi:
   - Buka Terminal cPanel / SSH.
   - Ketik: pm2 restart mci-approve-backend
   - *(Catatan: Server Anda sudah dilengkapi script watchdog otomatis per 3 menit di crontab, 
     sehingga jika mati akan otomatis menyala sendiri dalam 3 menit)*.

3. MEMASTIKAN KONEKSI DATABASE IBA AKTIF:
   Buka URL berikut di browser:
   https://approveanywhere.bprshikmciyk.co.id/api/health
   Jika muncul JSON dengan pesan "Backend API and Database Connection operational",
   maka backend dan database SQL Server IBA terhubung 100% normal.
